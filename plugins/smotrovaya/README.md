# Смотровая

**Продукт смотрится глазами, а не тестами.** Стенд гоняет реальное приложение по сценариям
и раскладывает снимки в ленту; человек листает ленту и по трём строкам замечания отдаёт
агенту адрес шага сценария, а не место в коде.

Закрывает точку подключения **`scenario-verification`** фреймворка
[Core Team](https://github.com/noxxer/core-team): доказательство, что сценарий проходится.

## Зачем

Стенд, зелёный на 183 шагах из 183, дефекты экранов **не фиксирует по построению**: он
проверяет, что шаг дошёл, а не что на экране правда. Разбор тех же 183 снимков глазами дал
восемь корней дефектов — включая карточку, которая печатала одну величину под именем другой,
оставаясь зелёной и спокойной.

## Понятия, которыми владеет этот плагин

| Понятие | English | Что это | Признак |
|---|---|---|---|
| **Снимок** | shot | снимок экрана с измеренной подписью | доказательство **шага сценария**; не эталон — попиксельно не сравнивают |
| **Лента** | deck | снимки прогона по порядку | листается подряд; границу сценария не пересекает |
| **Смотровая** | viewing room | место, где смотрят | **стенд снимает, Смотровая показывает** — «стенд упал» и «на Смотровой видно» про разные вещи |
| **Экран** | screen | смысловой экран продукта | не момент сценария: состояние данных идёт в `state`, а не в новое имя экрана |

Закон семейства — в карте ядра (`.claude/knowledge/artifacts-map.md`): снимок принадлежит
**Правде**, а не Работе. Он не задача — он доказательство.

## Девять инвариантов — коротко

Дубль снимка падает · подпись снимка измеряется, а не объявляется · пустой экран — находка ·
шаг толерантен, прогон честен · версия есть пара (код, прогон) · порядок версий по времени
прогона · прогон сериализует волну · локаль стенда — рабочая локаль продукта · лента без
мобильного снимка не покрывает мобильный случай.

Каждый куплен дефектом, у каждого есть замер. Подробности и цена — в `references/guards.md`.

## Чем не является

- **Не замена тестам.** Тесты отвечают «не сломалось ли», Смотровая — «что видно».
  Полный прогон идёт минуты, часть снимков стоит денег: это прибор для человека, не для CI.
- **Не сравнение снимков попиксельно.** С снимком не сверяют эталон — на него смотрят.
- **Не библиотека.** Стенд строится на том, чем проект уже гоняет браузер; каркас на
  Playwright разворачивается как образец, а не как догма.
