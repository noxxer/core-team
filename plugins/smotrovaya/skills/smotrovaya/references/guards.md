# Девять инвариантов стенда

Каждый куплен дефектом. Формулировка — «что запрещено», проверка — машинная, цена — замер
из боевого прогона. Гард без доказательства мутацией не принят: покажи, что он **краснеет
в мире с дефектом**.

## 1. Дубль снимка падает

**Запрещено:** шаг, чей снимок байт-в-байт совпадает с снимком предыдущего шага.

Такой шаг переснял тот же экран под новым именем — лента молча врёт о состоянии продукта.
Проверка: хэш содержимого снимка сравнивается с хэшем предыдущего.

**Обнуление базы сравнения:** шаг, помеченный началом нового потока (`newFlow`), не
сравнивается с последним снимком прошлого потока — это разные контексты.

**Законные исключения размечаются явно** — списком ключей `сценарий:экран:состояние` с
причиной у каждого. Пример законного: шаг-проверка по базе данных, вообще не трогающий
страницу; экран **действительно** не может измениться, потому что на нём нечего менять
действием, которого нет.

**Замер:** 33 снимка из 183 (18%), 16 групп в 7 сценариях из 9. После гарда — 2 из 183 (1.1%),
и **пять из семи срабатываний оказались настоящими дефектами сценариев**: клик жил внутри
предыдущего шага, а подпись утверждала переход, которого не было. Шесть дорожек, разбиравших
ленту глазами, нашли 4 группы из 16 — то есть четверть.

**Проверять независимым сканом, а не кодом возврата:** сверка `md5` по каталогу снимков
отвечает на вопрос «дубли есть?», exit-код отвечает на «гард сработал?». Это разные вопросы.

## 2. Подпись снимка измеряется, а не объявляется

**Запрещено:** писать в подпись то, что не измерено у страницы.

Устройство определяется **измеренной** шириной окна. Окно без размера (headless без явного
viewport) пишет `0` — «не измерено» честнее выдуманного значения, и подпись деградирует к
значению по умолчанию явно.

**Цена нарушения:** честный комментарий гардом не является. Строка в коде, словами
объясняющая, что число не измеряется, стоит рядом с продуктом, который печатает это число
как факт.

## 3. Пустой экран — находка, а не пустота

**Запрещено:** считать снимок удачным, если на странице нет ни одного текста.

Пустой `body` = отрисовался битый роут. Это находка, а не «нечего показывать».

## 4. Шаг толерантен, прогон честен

**Запрещено:** обрывать сценарий на первой ошибке — и **запрещено** рапортовать «прошло»,
если внутри есть сломанный шаг.

Шаг снимает снимок даже при сбое действия: снимок сломанного состояния — главная улика.
Завершение сценария **валит** прогон, если хоть один шаг лёг.

**Цена нарушения:** стенд рапортовал «passed» при сломанном checkout. Толерантность шага
была не тем местом, где терялся сигнал.

## 5. Версия — пара (код, прогон)

**Запрещено:** называть версию одним лишь хэшем кода.

Два прогона одного кода дают разные снимки: другие данные, другое время, другой ответ живого
движка. Схлопывание в одну папку затирает предыдущий прогон.

**Метка прогона выставляется один раз на весь прогон** — иначе сценарии, стартовавшие в
разные минуты, разъезжаются по разным версиям.

## 6. Порядок версий — по времени прогона

**Запрещено:** сортировать версии лексикографически.

Лексикографический порядок ставит первым тот прогон, чей хэш начинается с буквы поближе к
концу алфавита, и лента открывает **случайную** версию вместо последней.

## 7. Прогон сериализует волну

**Запрещено:** править дерево во время прогона.

Dev-сервер с горячей перезагрузкой подхватит чужой коммит посреди живого сценария: ярлык
версии назовёт один коммит, а часть ленты снята другим. Либо правки, либо снимки.

**Замер:** гипотеза названа с предсказанием ДО перегона и подтверждена 9/9 на чистом дереве —
три «таймаута» оказались чужим коммитом, приехавшим в середину прогона.

**Следствие для параллельной работы:** стенд — **единственный на контур ресурс**. Он
называется в брифе явно и получает владельца; запрета мутаций недостаточно.

## 8. Локаль стенда — рабочая локаль продукта

**Запрещено:** снимать в локали, отличной от той, в которой продукт живёт у пользователя.

**Прибор искажает ровно тот предмет, который им измеряют:** стенд снимал в англоязычной
локали две сессии подряд, и обе шли про даты.

## 9. Полнота устройств

**Запрещено:** считать ленту покрывающей продукт, если в ней нет ни одного мобильного кадра.

**Замер:** мобильный — основной случай, и он не был покрыт ни одной проверкой ленты, пока это
не заметили отдельной находкой. Цена названа явно: мобильные снимки удваивают прогон тех
сценариев, которые ими сняты, и если среди них есть дорогой — каждый полный прогон дорожает
на одно платное обращение.

## Как принимать новый гард

`Detect → Fix → Guard → Prove → Document`. **Prove** для стенда значит: назвать мутацию
(например, «гард не смотрит на `newFlow`»), внести её, показать красный прогон, снять —
показать зелёный. Гард, не виденный красным, — мнение, просто зелёное.
