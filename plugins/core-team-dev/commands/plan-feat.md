# Задача

Замысел: $ARGUMENTS

Четыре этапа одной лестницы. Понятия и признаки закрытия —
`.claude/knowledge/artifacts-map.md`.

| Этап | Артефакт | Закрывается, когда |
|---|---|---|
| **Идея** | `project/ideas/IDEA-NNNN-<slug>.md` | назван исход: фича · поставка · **отказ** |
| **Поставка** | `project/deliveries/DEL-NNNN-<slug>/DELIVERY.md` | **сценарий пройден насквозь** |
| **Путь развития** | `project/roadmap.md` | не закрывается — правится, как паспорт |
| **Фича** | `project/features/FEAT-NNNN-<slug>/README.md` | **у её шагов есть свежие снимки** |

## Шаг 1. Определи этап по входу — не спрашивай лишнего

| Вход | Этап |
|---|---|
| фраза, сырая мысль, «а что если» | Идея |
| идея с исходом «поставка» либо описание нескольких связанных фич | Поставка |
| готовая поставка, вопрос «в каком порядке» | Путь развития |
| один кусок работы, вопрос «что именно строим» | Фича |

Вход пуст или неоднозначен — спроси **одним** вопросом, с чего начинаем. Не угадывай
и не проходи всю лестницу, если человек пришёл с готовой фичей.

## Шаг 2. Разговор ведёт основная сессия

Субагенты запускаются **только для исследования и опросов** — они не принимают решений
и не пишут канонический файл. Роль голоса пользователя даёт материал; решает человек.

Вопросы — порциями по два-четыре. Значимая развилка задаётся через `AskUserQuestion`
с последствиями каждого варианта, информационные вопросы — прозой.

## Шаг 3. Что спрашивать на каждом этапе

**Идея.** Какая проблема? Какие свидетельства, что она есть? **Что критически неизвестно** —
то, от чего зависит, стоит ли вообще браться? Чем закончится, если не делать?
> **Отказ — законный исход.** Идея, закончившаяся отказом, — это сэкономленная поставка,
> а не потерянное время. Записывается вместе с причиной.

**Поставка.** Где граница результата? Что делает эти фичи **одним целым** — какой сценарий
проходится только когда выехали все? Что остаётся снаружи?
> Признак готовности: **назван сценарий**, который поставка закрывает целиком.

**Путь развития.** Чем определяется очередь? Что нельзя делать раньше чего? **Какой сигнал
открывает следующий горизонт** — не дата, а условие.

**Фича.** Путь действующего лица, краевые случаи, критерии приёмки. Каких шагов сценария
она касается.
> **Фича ссылается на сценарий полем `scenario:`, а не переписывает его.** Сценарий —
> слой правды и живёт в `scenarios/`; если точки `scenarios` нет, путь пишется прямо
> в требования фичи, и **это говорится вслух**: покрытие тогда не считается.

## Шаг 4. Запись

1. Номер занимается **до** записи: создай каталог или пустой файл, потом заполняй.
   Иначе два параллельных разговора возьмут один номер.
2. Шапка называет родителя: фича → поставка, поставка → идея, у поставки — `covers: [CLM-NN]`.
3. Правка поставки помечает соседний путь развития **устаревшим**, тело сохраняя.

## Шаг 5. Итог человеку — и следующая команда с аргументом

Скажи: вид, путь, два-четыре главных исхода — и **что запускать дальше**, точной строкой:

| Закрыли | Дальше |
|---|---|
| идею с исходом «поставка» | `/plan-feat` на поставку |
| поставку | `/plan-feat` на первую фичу пути развития |
| фичу, дерево ответственностей есть | `/spec` — сверить сценарий с деревом |
| фичу, дерева нет | `/plan` — проект изменения по требованиям |
| фичу, но цена неясна | `/change` — смета до согласия |

**Не заканчивай разговор без следующего шага.** Человек не обязан помнить, что идёт за чем.
