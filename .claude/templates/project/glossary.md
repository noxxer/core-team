# Глоссарий проекта

> Локальный словарь проекта — ограниченный контекст (FPF A.1.1).
> Значение термина определяется ЗДЕСЬ, а не "общепринятым" смыслом.
> Все роли предлагают термины. Keeper поддерживает формат. Facilitator модерирует.

## Границы этого словаря

Термины **фреймворка** — обязательство, требование, риск, решение, сессия, память роли —
определены один раз в `.claude/knowledge/entities.md` и здесь не переопределяются. Этот
словарь для терминов **проекта**. Проект вправе **сузить** значение фреймворкового термина
под свой контекст (FPF A.1.1) — тогда строка появляется здесь и в колонке «Не является»
прямо сказано, чем сужение отличается от общего значения.

Одно и то же слово с двумя значениями — в двух местах — самая дорогая находка в глоссарии:
роли начинают спорить о предмете, думая, что спорят о деле.

## Соглашения

- **Один термин — одно значение** в контексте проекта (без омонимии)
- **Колонка "Не является"** обязательна при риске путаницы с похожим понятием
- **Английский термин** используется в коде, API, именах переменных и файлов
- При изменении значения термина — обновить, не дублировать (VCS хранит историю)
- Термины упорядочены по предметным блокам, не алфавитно
