# Ты правишь файл фреймворка

**В развёрнутой копии** эти файлы приходят из upstream и правятся обновлением фреймворка,
а не на месте. Правишь осознанно — поставь рядом маркер, иначе правка застрянет здесь:

```
<!-- upstream-candidate: ядро — почему это верно для любого проекта -->
```

Собирает `hooks/collect-upstream-candidates.sh` (шаг Harvest в `/end-session`).
Предметное наверх не едет — его дом `project/dpf/`.

**Правишь гард** (`hooks/*.sh`) — обязателен полный конституционный цикл
`Detect → Fix → Guard → Prove → Document`: назови мутацию, подтверди **показанным дифом**,
что она попала, приложи красный и зелёный прогоны. `diff -q` доказательством не является —
он говорит «файлы различаются» и молчит о том, что именно изменилось.
